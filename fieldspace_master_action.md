# Proposed master action for the EFMW FieldSpace atlas

Status: proposed generating principle, October 2026. Not part of enuminous/FieldSpace. Not reviewed. Not fitted. Not a claim that the 11 sectors are physical fields.

The source file EFMW_165_field_equations.txt is a catalogue of 165 triplet blocks. This note supplies one action whose Euler–Lagrange equations restrict to those blocks. Geometry is taken as universal background structure (commentary interpretation A). E is the dynamical gravity channel: the metric is varied only in blocks that contain E. Gauge expressions are written in standard form; the source strings ∇_μ F_{μν}^{μν} and ∇_[μ F_{μν}_{νρ]} are treated as the divergence and Bianchi identity below, which is a normalization, not a silent rewrite of the source file.

## Fields

- Metric g_{μν}, signature (−,+,+,+). E means this metric is dynamical.
- U(1) gauge field A_μ, strength F_{μν} = ∂_μ A_ν − ∂_ν A_μ. Sector M.
- U(1) gauge field B_μ, strength S_{μν} = ∂_μ B_ν − ∂_ν B_μ. Sector S. The letter S is the source’s name for this strength; it is not the action.
- Real scalars φ_a, a ∈ {F, W, T, I, R, H, P, A}.

Units are not fixed. Every λ and κ below is a phenomenological coupling inherited from the catalogue.

## Action

\[
\mathcal{S}[g,A,B,\varphi]
= \int \mathrm{d}^{4}x\,\sqrt{-g}\,\mathcal{L},
\qquad
\mathcal{L} = \mathcal{L}_{E} + \mathcal{L}_{M} + \mathcal{L}_{S} + \sum_{a}\mathcal{L}_{a} + \mathcal{L}_{\mathrm{int}}.
\]

Einstein–Hilbert plus cosmological term:

\[
\mathcal{L}_{E} = \frac{1}{2\kappa}\left(R - 2\Lambda\right).
\]

Maxwell terms, conventional normalization:

\[
\mathcal{L}_{M} = -\frac{1}{4} F_{\mu\nu} F^{\mu\nu},
\qquad
\mathcal{L}_{S} = -\frac{1}{4} S_{\mu\nu} S^{\mu\nu}.
\]

Scalar sector, with the standard nonminimal term whose variation produces ξ R φ:

\[
\mathcal{L}_{a}
= -\frac{1}{2}\nabla_{\mu}\varphi_{a}\nabla^{\mu}\varphi_{a}
- \frac{1}{2} m_{a}^{2}\varphi_{a}^{2}
- \frac{1}{2}\xi_{a} R\,\varphi_{a}^{2}.
\]

Interaction Lagrangian. This is the definition the catalogue left open. ℜ is a specified curvature scalar, taken here as ℜ = R. A different invariant is a different theory.

\[
\begin{aligned}
\mathcal{L}_{\mathrm{int}}
&= -\sum_{a<b}\lambda_{ab}\,\varphi_{a}\varphi_{b}
- \sum_{a<b<c}\lambda_{abc}\,\varphi_{a}\varphi_{b}\varphi_{c} \\
&\quad -\sum_{a}\varphi_{a}\left(\lambda_{aE}\,\mathfrak{R} + \lambda_{aM} F_{\alpha\beta}F^{\alpha\beta} + \lambda_{aS} S_{\alpha\beta}S^{\alpha\beta}\right) \\
&\quad -\sum_{a}\mathfrak{R}\,\varphi_{a}\left(\lambda_{aEM} F_{\alpha\beta}F^{\alpha\beta} + \lambda_{aES} S_{\alpha\beta}S^{\alpha\beta}\right) \\
&\quad -\sum_{a}\gamma_{aM}\,\varphi_{a}^{2}\,\nabla_{\mu}\varphi_{a}\,A^{\mu}
- \sum_{a}\gamma_{aS}\,\varphi_{a}^{2}\,\nabla_{\mu}\varphi_{a}\,B^{\mu}.
\end{aligned}
\]

The last line is the phenomenological φ∇φ current in the catalogue. It is not gauge invariant. Setting γ = 0 restores U(1) invariance and deletes that current. That is the conservative choice.

## Defined interaction objects

Mixed stress, so T^{(int)}_{μν} is no longer a name:

\[
T^{(\mathrm{int})}_{\mu\nu}
= -\frac{2}{\sqrt{-g}}\frac{\delta(\sqrt{-g}\,\mathcal{L}_{\mathrm{int}})}{\delta g^{\mu\nu}}.
\]

Mixed gauge source:

\[
\Xi_{M}^{\nu}
= \frac{1}{\sqrt{-g}}\frac{\delta(\sqrt{-g}\,\mathcal{L}_{\mathrm{int}})}{\delta A_{\nu}},
\qquad
\Xi_{S}^{\nu}
= \frac{1}{\sqrt{-g}}\frac{\delta(\sqrt{-g}\,\mathcal{L}_{\mathrm{int}})}{\delta B_{\nu}}.
\]

External currents J_E, J_M, J_S in the catalogue are optional matter sources added by \int A_μ J^μ. They are not generated by the eleven sectors. If they are absent, delete them.

## Euler–Lagrange equations

Metric variation, included only when E is active:

\[
G_{\mu\nu} + \Lambda g_{\mu\nu}
= \kappa\left(T^{(M)}_{\mu\nu} + T^{(S)}_{\mu\nu} + \sum_{a} T^{(a)}_{\mu\nu} + T^{(\mathrm{int})}_{\mu\nu}\right),
\]

with the usual Maxwell and canonical scalar stresses. This is the catalogue’s Einstein block.

Gauge variation:

\[
\nabla_{\mu} F^{\mu\nu} = J_{M}^{\nu} + \Xi_{M}^{\nu},
\qquad
\nabla_{\mu} S^{\mu\nu} = J_{S}^{\nu} + \Xi_{S}^{\nu}.
\]

Bianchi identities are not equations of motion. They follow from the definitions of F and S:

\[
\nabla_{[\lambda} F_{\mu\nu]} = 0,
\qquad
\nabla_{[\lambda} S_{\mu\nu]} = 0.
\]

Scalar variation:

\[
\begin{aligned}
\square_{g}\varphi_{a} + m_{a}^{2}\varphi_{a} + \xi_{a} R\,\varphi_{a}
&+ \sum_{b\neq a}\lambda_{ab}\varphi_{b}
+ \sum_{b<c,\,b,c\neq a}\lambda_{abc}\varphi_{b}\varphi_{c} \\
&+ \lambda_{aE}\mathfrak{R}
+ \lambda_{aM} F_{\alpha\beta}F^{\alpha\beta}
+ \lambda_{aS} S_{\alpha\beta}S^{\alpha\beta} \\
&+ \mathfrak{R}\left(\lambda_{aEM} F_{\alpha\beta}F^{\alpha\beta} + \lambda_{aES} S_{\alpha\beta}S^{\alpha\beta}\right)
+ \mathcal{C}_{a}[\gamma]
= 0.
\end{aligned}
\]

C_a[γ] is the contribution of the non-invariant γ terms. It is zero if γ = 0.

## Projection rule

A catalogue block for a triplet τ is this system after the restriction

\[
\Phi_{V\setminus\tau} = 0,
\]

and after every coupling that names a sector outside τ is set to zero. V = {E, M, S, F, W, T, I, R, H, P, A}.

- If E ∉ τ, do not vary the metric. Keep □_g and R as background geometry.
- If M ∉ τ, set A = 0 and drop F² portals.
- If S ∉ τ, set B = 0 and drop S² portals.
- Scalars outside τ are set to zero, which deletes their pair and triple portals.

Under that rule the six catalogue classes fall out by counting: 56 three-scalar blocks, 56 one-gauge blocks, 28 gravity-plus-two-scalar blocks, 16 gravity-gauge-scalar blocks, 8 two-gauge-plus-scalar blocks, and one E–M–S block.

## What this fixes, and what it does not

It fixes the open definitions of T^{(int)} and Ξ, forces reciprocal pair couplings λ_{ab} = λ_{ba}, and makes overlapping triplets agree: the F equation in E–F–M and in E–F–W are the same master equation with different fields set to zero.

It does not fix units, choose numerical couplings, prove stability, or recover a measured limit beyond the empty statement that λ = γ = 0 and all but one scalar set to zero returns Einstein–Maxwell plus a Klein–Gordon field. The γ terms should be dropped unless a broken-gauge mechanism is supplied. Conservation ∇^μ T_{μν} = 0 holds on shell only for the gauge-invariant truncation γ = 0, by diffeomorphism invariance of the action.

Known-theory limit used as the failure condition: κ = 8πG, λ = γ = ξ = 0, Λ kept, only M active, gives the Einstein–Maxwell equations. Any later fit that cannot reach that limit is a different theory, not a restriction of this action.
